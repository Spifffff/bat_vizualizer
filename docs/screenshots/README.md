# Screenshot checklist

Screenshots placed in this folder under the filenames below will be picked up automatically, since the main
[README.md](../../README.md) already links to them. A PNG around 1200 to 1600 pixels wide is sufficient, and
there is no need to crop out the window chrome.

| Filename | What to capture |
|---|---|
| `main-window.png` | The main BatViz window with a recording loaded: waveform at the top, spectrogram below, a call visibly zoomed in, and a color scheme of your choosing. |
| `batident.png` | BatIdent partway through, or finished with, a folder: the progress bar, the results label showing the processed, skipped, and failed breakdown, and the log listing a few completed files. |

## Optional extras

These are useful additions but are not required for anything above to render correctly.

| Filename | What to capture |
|---|---|
| `heterodyne.png` | The playback options panel with Heterodyne selected and the tune-frequency slider set to a call frequency. |
| `measurement.png` | The spectrogram mid-measurement, with Shift-drag held, showing the duration, bandwidth, and slope readout. |
| `results-browser.png` | The Open folder view, showing the file list on the right with detections, sorted by confidence or timestamp. |

Any of these that are added should be referenced from the main README in the same way as the two required
screenshots: `![alt text](docs/screenshots/filename.png)`.
